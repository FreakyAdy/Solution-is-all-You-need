# Agent Tracking Protocol: Mandatory Post-Prompt Documentation Updates

Before completing any prompt turn in this repository, you MUST evaluate the work done and synchronize the following 5 documentation ledgers:

1. **`docs/DAILY_WORKBOARD.md` / `TODAY.md`**:
   - Check off completed items.
   - Update active session focus and next queue.
2. **`docs/CHANGELOG.md`**:
   - Record any code, config, or doc modifications under `[Unreleased]`.
3. **`docs/PROGRESS.md`**:
   - Update milestone tables and subsystem completion metrics.
4. **`docs/testing/INDEX.md`**:
   - Register any test executions, benchmarks, or dry-run outputs.
5. **`docs/DECISION_LOG.md`**:
   - Log any architectural or design trade-offs made.

Never output your final response to the user without completing this evaluation and updating the affected ledgers.
